# Man Hunt

משחק מחבואים עם מיקום אמיתי. לובי עם קוד, מחפש אחד (המארח בוחר כמה מחפשים), ועדכון מיקום כל 5 דקות.
האפליקציה היא PWA: מתקינים אותה מהדפדפן על הטלפון והיא נפתחת במסך מלא עם אייקון משלה.

## איך מעלים לאוויר (בחינם, בערך 5 דקות)

האפליקציה צריכה כתובת HTTPS כדי שהטלפון יאשר גישה למיקום, ושרת אחד שכל השחקנים מתחברים אליו.

1. פתח חשבון ב-GitHub והעלה את התיקייה הזו כמאגר חדש.
2. פתח חשבון ב-https://render.com ובחר New > Web Service, וחבר את המאגר.
3. הגדרות: Runtime = Node, Build Command ריק (או `npm install`), Start Command = `npm start`, תוכנית Free.
4. אחרי שה-Deploy מסתיים תקבל כתובת כמו `https://man-hunt-xxxx.onrender.com`. זו האפליקציה.

אפשר גם בלי GitHub: כל שירות שמריץ Node (Railway, Fly.io, שרת VPS) עובד. הפקודה היחידה היא `node server.js` והפורט נקרא מהמשתנה `PORT`.

הערה לגבי התוכנית החינמית ב-Render: השרת נרדם אחרי כמה דקות בלי פעילות, והפתיחה הראשונה אחריו לוקחת כחצי דקה. משחקים פעילים לא מושפעים.

## איך מתקינים על הטלפון

- אנדרואיד (Chrome): פותחים את הכתובת, לוחצים "התקן כאפליקציה" במסך הראשון (או תפריט ה-⋮ ואז "התקן אפליקציה").
- אייפון (Safari): פותחים את הכתובת, לוחצים על כפתור השיתוף ואז "הוסף למסך הבית".

בפעם הראשונה שהמשחק מבקש מיקום יש לאשר "בזמן השימוש באפליקציה".

## איך משחקים

1. כל אחד פותח את האפליקציה ומקליד שם.
2. אחד יוצר משחק ושולח לאחרים את הקוד בן 4 התווים.
3. כשכולם בלובי, המארח בוחר כמה מחפשים יהיו (או משאיר "אוטומטי": אחד, ומתשעה שחקנים ומעלה שניים) ולוחץ "התחל משחק". המחפשים נבחרים באקראי.
4. המחפש רואה מכ"ם עם המיקום האחרון שכל מתחבא שלח, והמרחק אליו. כשהוא תופס מישהו הוא לוחץ "נתפס".
5. המשחק נגמר כשכל המתחבאים נתפסו, או כשהמארח מסיים אותו.

המתחבאים לא רואים את המיקום של אף אחד. השרת שולח מיקומים רק למחפשים.

## חשוב לדעת

- האפליקציה צריכה להישאר פתוחה ומסך דלוק כדי לשלוח מיקום (היא מבקשת מהמכשיר לא לכבות את המסך). דפדפנים לא מאפשרים לאפליקציית ווב לעקוב אחרי מיקום ברקע. אם האפליקציה נסגרה, העדכון הבא נשלח ברגע שפותחים אותה.
- המצב נשמר בזיכרון של השרת. אם השרת מתאתחל, משחק שמתנהל באותו רגע נעלם. משחקים שלא היתה בהם פעילות 6 שעות נמחקים.
- בלי הרשאת מיקום אפשר להפעיל "מצב הדגמה" עם מיקום מדומה, כדי לנסות את המשחק בבית.

## הרצה מקומית

```
npm start
```

ואז לפתוח http://localhost:3000 במחשב. טלפון ברשת הביתית לא יאשר מיקום בכתובת HTTP רגילה, לכן לבדיקה עם מיקום אמיתי צריך כתובת HTTPS.

## מבנה

- `server.js` שרת Node בלי תלויות: ה-API של המשחק והגשת האפליקציה.
- `public/` האפליקציה: `index.html`, `manifest.webmanifest`, `sw.js` ואייקונים.
